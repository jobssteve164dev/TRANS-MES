# TRANS-MES (物料搬运通道仿真与尺寸评估工具)

这是一个用于评估和模拟刚性物体在带有拐角及杂物障碍的通道中搬运通过性与尺寸极限的 Web 工具。项目采用纯前端技术（HTML5 Canvas, Three.js, Tailwind CSS）构建，支持以单文件形式进行传阅、部署和离线使用。

## 🌟 核心功能

1. **自定义拐角通道**：支持自定义直道长度、宽度以及任意拐弯角度（如 $30^\circ \sim 150^\circ$）。
2. **三维物体配置**：自定义搬运物体的长、宽、高。
3. **圆柱体杂物避障**：支持在通道内放置多个圆柱体杂物，位置可通过“相对通道墙壁的偏移量”（纵向/横向）进行高精度定位。
4. **智能路径规划 (最佳路线)**：基于 $(x, y, \theta)$ 状态空间的三维 A* 启发式搜索算法，规划出一条与墙壁和杂物保持安全距离的最佳搬运路线。
5. **运动模拟与包络线**：流畅的 2D/3D 联动动画演示，展示物体的扫掠体积包络线（Swept Volume）以及瓶颈点。
6. **通道尺寸极限评估**：利用二分查找算法自动评估特定宽度下最大可通过的长度，或特定长度下最大可通过的宽度，并可一键绘制“长-宽可行尺寸边界曲线”（Design Space Envelope）。

## 📐 几何模型与相对坐标系

圆柱杂物的精确坐标可以通过自定义设置相对通道墙壁的坐标来确定：

* **段选择**：第 1 段直道（水平段）或第 2 段直道（偏转段）。
* **墙壁参考**：
  * **内侧墙壁**：拐角内侧的墙壁（即较窄转弯半径的一侧）。
  * **外侧墙壁**：拐角外侧的墙壁（即较宽转弯半径的一侧）。
* **纵向偏移**：对于第 1 段，指从入口沿通道向右的距离；对于第 2 段，指从拐角相交折点沿偏转方向向外的距离。
* **横向偏移**：垂直于参考墙壁，向通道中心内部偏入的距离。

## 🚀 运行与部署

本项目为自包含的单网页应用：
* 双击 `index.html` 即可在现代浏览器中直接运行。
* 可以无缝托管于任意静态网页服务（如 GitHub Pages, Vercel 等）。
